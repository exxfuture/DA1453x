2. Preparing the development kit

2.1. Supported Development Kits

Renesas offers a variety of development kits for the DA14535, DA14531-00, DA14531-01 and DA14585/6 Bluetooth® devices. In this tutorial we will be using one of the following development kits:

  • DA1453x DEVKT-P combined with a DA14535

  • DA1453x DEVKT-P combined with a DA14533

  • DA14531 USB Development Kit

  • DA14531 DEVKT-P combined with a DA14531 or DA14531-01 daughter board (FCGQFN24 package variant)

  • DA14585 BASIC Devkit

  • DA14585 DEVKT-P combined with a DA14585 or DA14586 daughter card

The DEVKT-P variants are recommended as they allow the user to more easily observe and verify the behavior of the firmware using the SmartSnippets™ Power Profiler tool. You can, however, still follow along using any development kits listed above.

In the following, we will define jumper and switch settings for each of the Development Kits. These jumper and switch settings should not be changed during the tutorial - unless specifically mentioned otherwise.

DA14531 variants

The DA14531-01 is a ROM variant of the DA14531-00, optimized for peripheral-only applications. It supports peripheral mode, freeing up more memory (approximately 25%) for Bluetooth LE applications. The two versions are pin-to-pin compatible. For more information Please take alook at DA14531 Getting started guide
